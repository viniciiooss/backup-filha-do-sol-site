Política de Privacidade

Última atualização: 20 de setembro de 2026

Aplicativo e finalidade

O Backup Filha do Sol é um aplicativo privado para macOS usado para copiar arquivos e pastas selecionados do Google Drive para um HD externo controlado pela usuária.

Dados acessados

O aplicativo solicita o escopo https://www.googleapis.com/auth/drive.readonly. Esse escopo permite ler e baixar arquivos do Google Drive, mas não permite criar, editar ou apagar arquivos na conta Google.

Uso, armazenamento e compartilhamento

  • Os arquivos são usados somente para realizar o backup solicitado.
  • O processamento ocorre localmente no Mac da usuária.
  • As cópias são armazenadas somente no HD externo escolhido.
  • As credenciais OAuth ficam armazenadas localmente na configuração do aplicativo.
  • Não há envio dos arquivos para servidores do desenvolvedor.
  • Os dados não são vendidos, compartilhados para publicidade nem usados para treinar modelos de IA.

Retenção e exclusão

A usuária controla os arquivos gravados no HD e pode apagá-los quando desejar. O acesso à conta Google pode ser revogado na página de segurança da Conta Google. A remoção do acesso não apaga as cópias já gravadas no HD externo.

Uso Limitado das APIs do Google

O uso de informações recebidas das APIs do Google seguirá a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
