Aplicativo privado para macOS

Backup Filha do Sol

Uma ferramenta de backup que copia pastas selecionadas do Google Drive para um HD externo, preservando versões anteriores e arquivos removidos da nuvem.

Como funciona

  • Solicita acesso somente leitura ao Google Drive.
  • Processa os arquivos localmente no Mac da usuária.
  • Grava as cópias apenas no HD externo escolhido pela usuária.
  • Não edita nem apaga arquivos do Google Drive.

Uso dos dados do Google

Os dados acessados são usados exclusivamente para executar o backup solicitado pela usuária. O aplicativo não possui servidor próprio, publicidade ou análise de comportamento.

O uso de informações recebidas das APIs do Google está em conformidade com a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
